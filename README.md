# MUSE

MUSE — концепт инструмента для поиска визуального направления из идеи или короткого описания.

Идея простая: у человека уже может быть мысль, настроение или несколько слов, но не всегда понятно, как превратить это в цельное визуальное направление. MUSE помогает пройти этот первый шаг — от слов к образу.

Пользователь описывает свою идею, а интерфейс показывает возможное направление: настроение, цветовую палитру, материалы, типографику и ключевые визуальные ассоциации.

## Что сделано

Проект собран как интерактивный frontend-прототип:

- адаптивный интерфейс;
- интерактивный генератор визуального направления;
- состояния генерации и результата;
- анимации появления элементов;
- responsive layout;
- поддержка `prefers-reduced-motion`;
- accessibility для интерактивных элементов;
- переключение русского и английского языков;
- сохранение выбранного языка;
- типизированные mock data;
- компонентная архитектура на React + TypeScript.

Генератор в текущей версии работает на mock data. Это сделано специально: задача проекта — показать пользовательский сценарий и frontend-реализацию интерфейса, а подключение реальной AI-модели можно добавить отдельно.

## Структура

Основные части проекта разделены по ответственности:

```text
src/
├── app/
│   └── App.tsx
├── components/
│   ├── layout/
│   └── ui/
├── data/
│   └── muse.ts
├── hooks/
│   ├── useCreativeDirection.ts
│   └── useReveal.ts
├── i18n/
├── sections/
├── styles/
├── types/
└── main.tsx
```

`App.tsx` остаётся точкой сборки страницы, а секции, переиспользуемые компоненты, hooks, данные и локализация вынесены отдельно.

## Локализация

Интерфейс доступен на двух языках:

- Русский (`ru`)
- English (`en`)

Язык можно переключить в Header. Выбор сохраняется в `localStorage`, поэтому после перезагрузки используется последний выбранный язык.

## Технологии

- React
- TypeScript
- Vite
- CSS
- React Hooks

Проект намеренно не перегружен зависимостями — большая часть логики реализована непосредственно на уровне React-компонентов и hooks.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить development server:

```bash
npm run dev
```

Для production build:

```bash
npm run build
```

## Примечание

MUSE — frontend-концепт, поэтому AI-генерация сейчас не подключена к внешней модели. Mock data позволяет полностью показать сценарий работы интерфейса без зависимости от API и внешнего backend.

Следующим шагом к полноценному продукту было бы подключение LLM, которая принимала бы пользовательский prompt и формировала реальные creative directions вместо mock data.
